# Taller Unidad5 Método de Organización Eficientes y Búsqueda Binaria
Realizado por:
Jessica Paola Narváez Tovar

## Descripción

Este proyecto desarrolla un sistema en lenguaje C para la gestión de pesos de contenedores en un patio de carga. El programa permite registrar pesos manualmente, generar datos aleatorios, visualizar los contenedores almacenados, ordenar los datos mediante un método de ordenamiento eficiente (Quick Sort) y realizar búsquedas utilizando el algoritmo de búsqueda binaria.

## Funcionalidades

* Registro manual de pesos de contenedores.
* Generación aleatoria de pesos.
* Visualización de los pesos almacenados.
* Ordenamiento eficiente de los datos.
* Búsqueda binaria de un peso específico.
* Control del estado del arreglo mediante una bandera de ordenamiento.

## Tecnologías utilizadas

* Lenguaje C
* Visual Studio Code
* GCC
